# Code of Conduct

## Our standard

This project is for practical, respectful collaboration. Contributors should be
direct, constructive, and focused on improving the software.

Examples of expected behavior:

- Be clear and specific when reporting bugs or reviewing code.
- Assume good intent while still asking for evidence and tests.
- Keep discussions focused on the issue, pull request, or design tradeoff.
- Respect maintainers' time by keeping pull requests scoped.

Examples of unacceptable behavior:

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without permission.
- Repeatedly derailing technical discussions.
- Dismissing requested reproduction steps, tests, or review feedback.

## Enforcement

Maintainers may edit or remove comments, close issues, block users, or take other
reasonable action to keep the project healthy. If you need to report a conduct
problem, contact a maintainer privately.
